# Release 0.11.4

## Changes

- The floating toolbar now remembers where you dragged it across page reloads and after closing and reopening the tab. The position is saved per site.
- When no position has been saved, the toolbar starts at the top center of the page instead of the right edge.

Positions saved by earlier versions only lasted for the tab session, so they are not carried over; drag the toolbar once to set it again.

## Install

Download `videospeed-0.11.4.zip` below, unzip it, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. To update an existing install, replace the folder's contents and click reload on the extension's card.
