# Release 0.11.3

## Changes

- The options page **About** and **Send Feedback** buttons, and the extension's homepage link, now open this fork ([kookob/videospeed](https://github.com/kookob/videospeed)) instead of the upstream repository.
- The README describes how to install the fork from GitHub Releases and how it differs from upstream.

## Install

Download `videospeed-0.11.3.zip` below, unzip it, open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**. To update an existing install, replace the folder's contents and click reload on the extension's card.
